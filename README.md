One job title, 35 characters, the weirdest I could think of. A blind judge
compares titles two at a time and picks the weirder, funnier one.

## The entry

> **Professional Ghostwriter for Ghosts**

A real-sounding job — ghostwriting is a genuine profession — with one
hilariously specific twist: the clients are literal ghosts.

The title is 35 characters, inside the competition's 1–60 character gate,
and `main.ts` validates that length before writing anything, so an invalid
entry fails loudly instead of reaching the judge.

## Run

```sh
node main.ts
```

Writes the entry text to `/output/entry.txt`.
